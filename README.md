# S&D Pets - Landing Page

Landing page do pet shop **S&D Pets** (Carapicuíba - SP), em HTML, CSS e JavaScript puro.

## Arquivos
- `index.html` - página completa (HTML + CSS + JS)
- `logo.png` - logotipo

## Publicar no GitHub Pages
1. Envie os arquivos para a raiz do repositório.
2. Em **Settings > Pages**, escolha a branch `main` e a pasta `/ (root)`.

## Editar
- Links e horários: objeto `LINKS` e `HOURS` no início do `<script>`.
- Depoimentos: troque os textos entre colchetes pelas avaliações reais do Google.
- Domínio: ajuste `canonical` e `og:url` no `<head>`.
